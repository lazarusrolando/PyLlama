PYLLAMA MODELS FOLDER
=====================

PyLlama does NOT download models and does NOT use a Hugging Face API.

Download a compatible GGUF model yourself with your browser or another tool,
then copy the .gguf file into this folder.

Examples:
    models\Qwen3-0.6B-Q4_K_M.gguf
    models\Llama-3.2-3B-Instruct-Q4_K_M.gguf

You may also organize models in subfolders:
    models\Qwen3-0.6B\Qwen3-0.6B-Q4_K_M.gguf

Run `run.bat` from the project root to inspect and execute installed models.
